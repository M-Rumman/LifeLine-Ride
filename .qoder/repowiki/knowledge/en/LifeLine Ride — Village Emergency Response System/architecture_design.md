The project is split into two cooperating children: `backend` implements the Module 1 triage/dispatch pipeline and Module 2 Urdu help-bot session as a FastAPI HTTP API backed by PostgreSQL, while `mockdata` provides scripted conversation branches, replay logs with per-turn expectations, cached TTS audio, and voice/photo assets. Both children share Incident data contracts and seed responders/BHUs so the backend can run end-to-end against mock conversations without external services. Top-level docs (`PROJECT.md`, `DEMO_SCRIPT.md`, `village-emergency-response-system-spec.md`) define the multi-module architecture and the 3-minute demo flow that ties reporter registration, responder guidance, escalation, and outcome tracking together.
