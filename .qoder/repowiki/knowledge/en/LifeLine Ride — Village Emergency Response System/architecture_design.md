The root orchestrates three cooperating services around one shared incident domain: the `backend` (FastAPI) owns in-memory state reconciled against PostgreSQL and exposes Modules 1–9 of the spec; the `frontend` (React/Vite) renders role-based views bound to a shared incident context and live timeline feed consumed from the backend; the `mockdata` package supplies scripted Urdu conversation branches, replay logs, TTS audio, and voice/photo assets that drive and validate the help-bot flow exercised by both backend sessions and frontend demos. Cross-child wiring is driven by the incident lifecycle defined in `village-emergency-response-system-spec.md` and `PROJECT.md`, with the frontend calling the backend's HTTP API and the mock fixtures being replayed against the backend's help-bot session endpoints during demo and testing.
