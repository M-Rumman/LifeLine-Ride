The workspace is split into two cooperating children: `backend` (Python service implementing Module 1's triage/dispatch pipeline and Module 2's Urdu help-bot session) and `mockdata` (static scripts, replay logs, cached TTS audio, and voice/photo assets that drive and validate those same pipelines). Both children share Incident data contracts and seed data so the backend can run end-to-end against the mock conversation branches without external services. Top-level docs (`PROJECT.md`, `DEMO_SCRIPT.md`, `village-emergency-response-system-spec.md`) define the multi-module architecture (Modules 1–9) and the 3-minute demo flow that ties reporter registration, responder guidance, escalation, and outcome tracking together.
