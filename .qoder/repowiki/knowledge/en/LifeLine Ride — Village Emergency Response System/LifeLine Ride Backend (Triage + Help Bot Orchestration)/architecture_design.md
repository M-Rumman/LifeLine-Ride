The `backend/` directory is a flat orchestration layer: `slice_runner.py` defines the shared data contracts (`Incident`, `Responder`, `BHU`, `DispatchResult`) and runs the Module 1 triage pipeline (STT → vision → classifier → dispatch) with a swappable AI provider (Gemini or DashScope via `TRIAGE_AI_PROVIDER`). `help_bot_runner.py` is the Module 2 console entrypoint; it imports `slice_runner` to build incidents (either from simulated flags or by invoking the real pipeline via `registerIncident`), calls `matchResponderAndBHU` and `dispatch` to reuse Module 1's matching logic, then hands the resulting `Incident` to `HelpBotSession` in `services/help_bot_service.py`. The two modules communicate exclusively through these shared Pydantic models and the `help_bot_transitions` list appended on `Incident` for later accountability review. `verify_stt.py` and `verify_vision.py` are standalone verification scripts that import the same `slice_runner` functions to exercise individual AI steps against mock media.
