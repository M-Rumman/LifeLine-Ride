The module is a flat collection of static fixtures consumed by the help-bot test harness. It has two top-level areas: `helpbot/` holds scenario definitions and results — `scripts/*.json` declare ordered turn sequences with expected intent labels (`step_done`, `in_scope_question`, `out_of_scope`, `escalation`) that drive branch matching; `test_runs/*.json` are full replay artifacts recording bot/responder turns, per-turn latency, state transitions (`branch_entered`, `step_started`, `in_scope_question`, `escalation_triggered`, `session_finalized`), and the final incident object with flags and severity tier; `tts_cache/manifest.json` maps SHA1 filenames to Gemini TTS model/voice/text metadata alongside `.wav` files. `media/` provides reusable assets: `voice/*.txt` paired with `.mp3` recordings (e.g. snakebite, taang, ungli) used as simulated user input, plus `photos/` placeholder images and a `.triage_cache/` directory for triage tooling artifacts. There is no executable code here — the JSON schemas in `scripts/` and `test_runs/` form the contract between the simulator and the help-bot engine.
