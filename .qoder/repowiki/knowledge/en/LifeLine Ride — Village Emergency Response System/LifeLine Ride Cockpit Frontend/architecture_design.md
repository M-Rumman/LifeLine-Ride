The app is bootstrapped by `main.tsx` into a StrictMode root and renders `App`, which wraps everything in `CockpitProvider` from `state/CockpitContext`. The provider holds the single source of truth for the active role, incident record, triage verdict, help-bot transcript, timeline events, and toast notifications; all three role views (`ReporterView`, `ResponderView`, `BhuView`) mount/unmount via a switch in `App` but never own state — they read/write exclusively through `useCockpit`. The layout is a fixed 60/40 grid: the left panel shows the active role's step banner plus view, while the right panel permanently mounts `SituationMap` (Leaflet) and `TimelineFeed` so every role observes the same live data. Cross-cutting concerns are centralized: `lib/api.ts` handles HTTP calls with polling via `hooks/usePoll.ts`, `lib/types.ts` defines shared TypeScript contracts consumed by both views and components, and `lib/scenarios.ts` seeds demo incidents. UI primitives (`components/ui.tsx`) and Tailwind utility classes provide consistent styling across all children.
