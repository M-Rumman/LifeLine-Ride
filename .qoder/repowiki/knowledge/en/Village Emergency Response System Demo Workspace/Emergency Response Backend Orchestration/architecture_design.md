The `backend/` package is a flat orchestration layer centered on `slice_runner.py`, which defines the shared Pydantic contracts (`Incident`, `Responder`, `BHU`, `DispatchResult`, `GPSLocation`) and implements the Module 1 triage pipeline (STT → vision → classifier → dispatch) with a swappable AI provider selected via `TRIAGE_AI_PROVIDER`. `help_bot_runner.py` is the Module 2 console entrypoint: it imports `slice_runner` to build incidents either from deterministic simulated flags or by invoking the real pipeline through `registerIncident`, reuses `matchResponderAndBHU` and `dispatch` for matching logic, then hands the resulting `Incident` to `HelpBotSession` in `services/help_bot_service.py`. The two modules communicate exclusively through these shared Pydantic models and an additive `help_bot_transitions` list appended on `Incident` during the help-bot session for later accountability review. Standalone scripts `verify_stt.py` and `verify_vision.py` exercise individual AI steps against mock media using the same `slice_runner` functions, keeping all cross-module wiring in this single package.
