Three top-level files form the application root: `main.tsx` is the single entry point that creates a ReactDOM root on `#root`, imports global styles, and wraps `<App />` in `StrictMode` (kept intentionally on to guard against Leaflet duplicate-instance and `usePoll` race regressions). `App.tsx` exports the default component that provides `CockpitProvider` from `./state/CockpitContext`, then renders the `Cockpit` layout — a two-column grid (60% left workflow panel, 40% right sticky sidebar) composed of `Header`, a role-specific view (`ReporterView` / `ResponderView` / `BhuView`) selected via a switch on the current `role`, plus the always-visible `SituationMap` and `TimelineFeed`. A local `RolePanel` mounts only the active view so shared incident state in `CockpitContext` remains stable across role switches. A `ToastStack` component renders non-blocking notifications sourced from the same context. `index.css` establishes the dark 'Impilo Clinical Observatory' design system using Tailwind directives (`@tailwind base/components/utilities`), CSS custom properties for colors, and scoped overrides for Leaflet's basemap, markers, popups, and animated route vectors; it also defines reusable `.card`, `.pill`, `.field`, and `.tag` component classes.
